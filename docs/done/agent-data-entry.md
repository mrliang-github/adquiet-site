# Agent 公司数据入口

状态：`merge-ready`。已完成本地实现与验证，未推送、未部署；线上平台用量与新增路径 CDN 验收未完成。

## 目标

为外部 Agent 提供无需执行网页脚本即可读取的公司快照、字段与来源说明。请求只读取预生成文件；筛选、推理和分析由调用方完成。

## 范围与边界

- `/data/agents/` 提供使用说明，`manifest.json` 是小体积的发现入口，`README.md` 可直接交给 Agent。
- 按省份或国家分组，每块最多 100 条；保留完整快照下载，按内容哈希生成版本网址。字段采用现有公开数据的白名单，保留快照日期和来源，不承诺实时招聘或有效资格。
- 清单短缓存；含内容哈希的快照、索引与分块长缓存。只对新增公开数据路径设置规则，不新增函数、模型调用、数据库或后台轮询。
- 构建时检查 Astro 实际路由元数据、预生成文件、404、运行时函数缺失、分块记录/体积预算、链接和缓存规则，并接入正常生产构建。
- 线上只做低频缓存、条件请求和内容隔离抽查；并发验证仅针对本地生产产物，不能作为 Cloudflare 容量证明。后台用量与账号额度若无可用权限则保持未知。

## 实际完成

- `/data/agents/`、`manifest.json`、`README.md`、`schema.json`、`/llms.txt` 及 123 份清单引用的数据文件已静态生成。两套数据共 5,084 条，按 31 个省份和 52 个国家/地区分组，每块最多 100 条。分组排序固定，不依赖构建机器的地区排序配置。
- 内容版本覆盖名单与业务补充资料，分块网址含版本；资源同时提供字节数、SHA-256 与 gzip 参考体积。清单短缓存，版本文件长缓存；旧版本失效时要求重读清单且避免无限重试。
- 数据白名单、来源、日期与使用范围保留；页面有可复制的 Agent 提示文字，不请求模型或自动下载全库。
- Agent 数据契约 7 项测试通过；Astro 检查 167 个文件，0 错误、0 警告、3 条原有提示；最终生产构建 115 页成功。
- 构建真实路由元数据中，28 个项目 page/endpoint 均预渲染，无动态例外。检查器验证实际预生成文件、404/noindex、分块还原、预算及缓存路径，已接入正常构建与 CI；额外注入假动态路由的负向检查被正确拒绝。
- 本地静态预览夹具按 `_headers` 与 ETag 模拟缓存协议，4 并发 / 160 次读取错误 0，条件请求返回 304；不是 Cloudflare CDN 或生产容量压测。
- 浏览器按广东省读取 7 个分块，691 条记录中筛出 6 家传感器相关企业；桌面与 390px/320px 手机检查通过。最终离线预览的数据清单、地区索引和完整 JSON 链接可打开，正式域名链接需部署后才可供远程 Agent 使用。
- 已有生产 JSON 的低频读取返回 200，条件请求 304；一个无认证 Cookie 样本内容一致且没有 Set-Cookie。旧线上 404 状态正确，noindex 的本次修复尚未部署。未取得新路径线上 HIT 或平台 CPU/额度快照。
