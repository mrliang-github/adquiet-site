# 潜力公司库表格视图

## 问题与范围

求职者需要连续浏览、筛选和对比企业。原来的双列卡片把地区、业务与来源分散在不同位置，比较成本较高。本次将两份企业查询结果改为语义化表格；首页和公司库入口不变，数据内容、筛选逻辑、分页与 CSV 列保持原样。

## 设计与文件边界

- `CompanyRow.astro`：首屏静态表格行；名称、名单序号、地区、业务资料、网站线索对齐，胡润榜单增加独立估值列。
- `[slug].astro`：表头、行标题、表格说明和横向滚动区域；无 JavaScript 时仍可读前 24 条记录。
- `catalog-browser.ts`：筛选后的客户端表格行及合法的跨列空结果状态；继续使用文本节点与安全网址过滤。
- `catalog.css`：紧凑行距、交替底色、两行业务摘要；原生 details 展开完整介绍与来源。手机端保留表格，可横向滚动，企业名称固定在左侧。

检查 Astro 类型和构建、既有目录数据测试，以及两种表格的筛选、分页、空结果、来源展开和导出。实看桌面与手机页面，核对页面本身无横向溢出、表格横向滚动时公司名可见。验证失败加载时的静态回退与正常客户端结果保持一致。
