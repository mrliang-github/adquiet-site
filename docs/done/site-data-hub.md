# 企业资料库与内容入口预览

状态：`preview-only`。功能已实现并完成本地构建与交互检查；本次不推送、不部署。

## 目标和范围

面向中文读者，把个人站整理为能完成任务的入口：查企业资料、找工具、阅读可操作的攻略。保留个人产品与实践记录的主线。第一版验证信息架构与查询体验，不宣称已验证流量增长。

本分支 `feat/site-data-hub` 接在未合入的首页文案提交 `7332d12` 上；上线时须一并包含该提交，或先合入首页分支再同步。原有 `src/assets/styles/app.css` 和首页横幅样式不属于本次提交。

## 体验与技术

沿用 Astro 静态输出与现有主题，无新增服务、数据库或依赖。列表首屏由服务器生成 HTML，提供来源说明与数据范围；JavaScript 加载全量数据后启用搜索、地区/行业筛选、业务资料筛选、排序、分页、当前结果 CSV 导出和可分享的筛选网址。

企业详情在列表内展开，不批量制造几千个只有名字的独立 URL。文本使用 DOM textContent / Astro 转义；外链仅 HTTP(S)，禁用带用户名密码的 URL；CSV 防电子表格公式注入。查询词不发送到外部服务。

## 内容与增长路线

第一阶段以两个可用查询页、资料使用指南和现有实操文章构成入口。热点攻略使用同一攻略入口，内容必须有具体任务、适用时间、原始来源与实际步骤；没有已完成内容时不展示空的热点栏目。

后续优先围绕现有主题扩展：企业业务调研、资料整理、AI 工作流、文件处理。按搜索词和工具实际使用选择专题，避免泛热点与个人站主线脱节。数据快照更新与文章修订时间分别维护，不伪造更新日期。

搜索判断依据：Google 的[有帮助的内容指南](https://developers.google.com/search/docs/fundamentals/creating-helpful-content)与[规模化内容政策](https://developers.google.com/search/docs/essentials/spam-policies#scaled-content)。本地快照来源为[胡润榜单](https://www.hurun.net/zh-cn/rank/hsrankdetails?pagetype=unicorn)。未取得本网站 GSC/百度站长查询、关键词量或转化数据，本版不承诺流量效果。

发布后再观察查询页曝光、自然搜索入口、查询/筛选完成率、导出使用和相关工具访问；本次不增加第三方追踪或修改账号设置。
