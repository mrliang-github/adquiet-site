A useful answer, not more noise

From “my Mac is hot” to a grounded next step.

Activity Monitor can show CPU numbers. HeatSleuth combines live system state, related current-user processes, and a cautious action flow so you can understand what is worth handling.

01

Find the load source

Group related current-user processes into a meaningful workload, then surface the task that has stayed expensive instead of chasing a momentary spike.

02

Read the evidence

Keep process facts distinct from whole-Mac signals such as CPU, thermal state, temperature, and fan data, so the app does not pretend to prove more than it can.

03

Verify the result

When you choose to end an eligible process, HeatSleuth rechecks its identity, confirms exit, and compares the following two minutes of whole-Mac signals.

The real app

A compact dashboard for heat, workload, and evidence.

HeatSleuth stays readable when you need to make a decision quickly. It does not create sample history or invent a “hot” event when your Mac is running normally.

Focused boundaries

Built to explain a decision, not take control away from you.

HeatSleuth reads the information needed for diagnosis and keeps the final decision with you. It does not become a fan controller, cleaner, remote admin tool, or cloud dashboard.

  • All metrics, task attribution, and session events stay in local memory.
  • No account, cloud sync, tracking SDK, network service, or administrator Helper.
  • Only the current user’s tasks are considered; sensitive command-line details and full paths are not retained.
  • Ending a process requires a user action, identity recheck, and confirmation; HeatSleuth never ends tasks automatically.

Compatibility

Clear about what varies between Macs.

The release is universal and requires macOS 14 or later. The complete hardware matrix is still being expanded with real test devices.

  • Current complete device validation: Apple M4 Pro on macOS 26.5.2.
  • Sensor coverage: available temperature, fan, GPU, battery, and other metrics depend on hardware and macOS support.
  • Safe fallback: unavailable data remains visibly unavailable; it is never replaced with a made-up reading.

Questions

Before you download.

Does HeatSleuth upload my Mac data?

No. Metrics, task attribution, and session events are processed locally in memory. There is no account, cloud sync, or network service.

Can HeatSleuth control my fan?

No. It reads available thermal and fan information for diagnosis. It does not change your fan policy or control hardware cooling.

What if a sensor is unavailable on my Mac?

HeatSleuth labels unavailable, restricted, and temporarily failed readings rather than showing a made-up number. Sensor availability varies by Mac model and macOS version.

How do I install HeatSleuth?

Download and open the notarized DMG, drag HeatSleuth.app to Applications, then open it. The current direct-download build requires macOS 14 or later.

Can I end a process from HeatSleuth?

Only after you choose an eligible current-user process and confirm it. HeatSleuth rechecks identity before action and uses a cautious escalation path instead of automatically killing tasks.
