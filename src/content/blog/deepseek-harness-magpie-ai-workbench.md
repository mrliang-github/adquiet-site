手里同时开着好几个 AI 会员、电脑上装着三四款编程工具的人，最近很值得试试 **`DeepSeek Harness`（简称 `dsh`）+ `Magpie`（喜鹊）** 这两个工具，组合在一起用起来实在太爽了。

打个比方就能明白它俩的分工：`DeepSeek Harness` 给的是一副可以随便拆装的**骨架和四肢**，各家好用的大模型和工具库才是里面的**内核**。`Magpie` 负责把你散在各处的会员账号、Skill 和 MCP 傻瓜式聚拢过来，`DeepSeek Harness` 负责让你像早年给安卓手机刷机装模块一样，把这个 Agent 改成你自己独一无二的工作台。

## 1. DeepSeek Harness：像魔改安卓一样自由，一句提示词就能装齐

先说为什么选 `DeepSeek Harness` 当外壳，最直观的感受就是**可玩性大，而且本身不限制登录方式**。

它虽然是 DeepSeek 官方开源的桌面工作台，但没有绑死自家的接口——你接 DeepSeek 官方的 API 可以，接其他平台的第三方 API 也照样能跑。最吸引人的是它的插件生态，底层几乎所有模块都能做成插件：嫌默认界面不够顺手，可以直接装别人写好的社区插件；自己平时有点想法和创造力，也能直接在里面开 `Creator Mode` 动手搓新插件热加载上去，自由度跟以前魔改安卓手机的感觉很像，每个人改出来的结构都不一样。

而且装这套东西根本不用自己去折腾复杂的命令行环境。我月初装的时候，直接把下面这一句提示词发给本地 AI 让它去装：

```text
帮我安装 DeepSeek Harness 的 app，并且安装下面这些插件：

dsh-market、DSH-better-sidebar、DeepSeek-Balance-Whale-Widget、dsh-context、dsh-pet
```

结果它一路自动把桌面版 App 和这 5 个常用插件全装好了：`dsh-market` 用来在界面里直接逛市场装插件，`DSH-better-sidebar` 把侧边栏改造成多项目工作区，`DeepSeek-Balance-Whale-Widget` 是看余额的小鲸鱼挂件，`dsh-context` 用来透视上下文消耗，再顺手带个桌宠 `dsh-pet`。

装完把原有的个人规则 `AGENTS.md` 软链过来，左边栏按日常业务拆成 `项目`、`公众号`、`自媒体`、`数据分析` 几个分组，底下再挂上每晚 `22:00` 自动跑的《生财有术风向标·每日日报》和《每日职场英语场景对话》，一副顺手的骨架就搭好了。

## 2. Magpie（喜鹊）：比 CC Switch 傻瓜太多，点两下聚齐所有会员

有了能随便 DIY 的骨架，下一步就是往里面塞好用的大模型内核——把这件事干得最漂亮的就是 `yetone` 开源的 **`Magpie`（喜鹊）**。

如果你跟我一样开了很多个 AI 或 Agent 的会员，用它反代出来直接塞进 `DeepSeek Harness` 里调，体验比以前省事太多了。

我 9 月份折腾过用 `CC Switch` 把外部账号接进 `DeepSeek Harness`，那时候还得单独新建配置目录、开本地端口、再去填协议和占位密钥，配起来挺麻烦。换到 `Magpie` 之后完全是傻瓜式的：直接在「供应商」里登录你的账号，再去「Agent」列表里把需要使用这些反代接口的工具（比如 `DeepSeek Harness`；其实平时用 `WorkBuddy`、Claude Code 或 Codex，也一样可以把反代出来的模型放进去用）开关点开，它就会在本地自动路由到配置好的地方，打开对应的 Agent 直接就能选模型干活。

![Magpie 官方中文界面：一处打开接入开关，即可为本地各家 Agent 统一路由模型](https://img.liangxiaoaitool.top/2026/11/dsh-magpie-20261119-01-agents-route.png)

像我自己手头攒了一堆不同渠道的会员，全都被我收进了 `Magpie` 一个地方：

- 之前薅的 **2 个谷歌 AI Pro 会员**，直接反代过来日常简单跑一跑，还是挺耐用的；
- 上次花 400 多块开的 **土区谷歌 AI Ultra 会员**，加上这两天刚 **0 元购拿下的 5 倍额度谷歌 AI Ultra 会员**（注：截至发文该活动已失效）——光谷歌这儿就有 4 个号绑在里面；
- 手里还有 **2 到 3 个 Grok 的蓝 V 会员**，把 Grok 也顺手反代出来了；
- 电脑本机登过的 **GPT（Codex）**，它更是直接自动识别绑了过来。

同一家绑了多个账号时，还能建个路由组开 `smart`（智能）模式——它会优先挑最快到重置时间的那个账号用，尽量不让快过期的额度白白作废；只要提示词缓存还有效，同一轮对话也会稳稳留在同一个账号上不乱跳。

## 3. 不止共用模型，「资源库」还能把指令、Skill、MCP 和子代理全打通

电脑里装过三四个 Agent 的人都知道，比切模型更烦的是“搬家当”：Claude Code 读 `~/.claude`，Codex 读 `~/.codex/config.toml`，`DeepSeek Harness` 读 `~/.dsh`，`WorkBuddy` 又读 `~/.workbuddy`。以前新装一个工具，常用的 Skill、MCP 服务器和个人指令就得换着格式重新配一遍。

`Magpie` 顶部的 **「资源库」（Library）** 直接把这块痛点顺手解决了。它把 **全局指令（Instructions）、MCP 服务器、技能（Skills）、Hooks 和子代理（Subagents，也就是自定义 Agent 库）** 收进同一页统一维护：

![Magpie 资源库全局互通机制：指令、Skill、MCP 与子代理只配一次，全机 Agent 勾选共用](https://img.liangxiaoaitool.top/2026/11/dsh-magpie-20261119-02-library-hub.png)

第一次用的时候，直接点「从 Agent 中已有 → 全部导入」，就能把散落在旧工具里的配置一键收拢过来；之后想让哪个工具用，直接勾上开关，`Magpie` 会自动转换成各家对应的文件格式写进去（卸载或取消勾选时也只删它自己写的那一段，不会弄乱你原本的配置）。像我自己本机就把剪视频用的 `chatcut` MCP 和操作网页的 `ego-browser` 技能一键勾给了 `DeepSeek Harness`、Claude Code、Codex、Cursor、Antigravity、`WorkBuddy` 等 9 个本地 Agent 共用，再也不用挨个目录复制粘贴了。

顺手去翻了一下官方文档和 X 社区里的玩法，发现「资源库」里还藏着几个很实用的细节：

- **`MCP 路由` 与 `Skill 路由`（防上下文撑爆）**：如果把十几个 MCP 和几十个 Skill 全量塞进每个 Agent，不仅电脑后台要重复起一堆进程，光工具定义就能把上下文塞满。打开这两个路由开关后，命令型 MCP 全机只跑一份进程；工具超过 10 个时，默认只给 Agent 暴露轻量的按需检索调用接口，对上具体任务再去加载对应的工具或 `SKILL.md`。
- **项目级开关与跨电脑同步**：不想全局挂着的重型工具，可以在单个项目卡片里单独关掉；整套配置和技能库还支持用坚果云（WebDAV）、S3 或私有 GitHub 仓库加密同步到另一台电脑，里面甚至带了 `billion-context` 标签，能给 `DeepSeek Harness` 等工具自动折叠超长对话的早期轮次。
- **两个实操小边界**：目前 `DeepSeek Harness` 同步全局指令、Skill 以及 `stdio / streamable-http` 协议的 MCP 都没问题（老式 `SSE` 会自动跳过）；而给 `WorkBuddy` 勾选新 MCP 之后，记得进 `WorkBuddy` 自己的 MCP 设置里手动点开一次开关才会真正连上。

## 4. 全局额度看板 + 一条实在边界：主力大号我为什么只看不调

把七八个账号和工具库全收进 `Magpie` 之后，还有两个每天都会瞄一眼的核心功能：**一个是集中看所有账号的剩余额度，另一个是汇总本机所有本地 Agent 的总消耗量。**

不过虽然上面那些号我都绑上去了，像谷歌 Ultra、GPT 这些主力账号，我平时其实不会真拿去跑反代——**因为跨工具反代会员目前确实存在封号风险。** 比如这两天谷歌刚开始严查模拟客户端的第三方通道，集中报了一批 `403`（`Magpie` 官方也在新版里下线了内置的旧模拟登录，改推走本机正版命令行的 `opencode-agy-cli-auth` 插件；如果你之前手动装过旧的 `opencode-antigravity-auth` 插件，记得去插件列表里删掉，免得后台定时任务默认调过去）。像薅来的 Pro 小号拿来简单跑跑还行，真金白银开的主力大号还是留在原厂软件里用最稳妥，日常自动化杂活直接接正规便宜的官方 API 就够了。

即便很多主力号不动，我平时还是开着这套组合，主要就是拿它当**全局 AI 消耗看板**用（顺带一提，`Magpie` 界面右上角还自带了「邮箱打码」按钮，平时截图分享也不用怕露账号）。

在 `Magpie` 里扫一眼，手头哪家会员额度还剩多少、本地几个 Agent 各自跑了多少量一目了然；再点开 `DeepSeek Harness` 左边栏的「上下文洞察」（`dsh-context`），连每一笔 Token 具体烧在哪儿都能扒得明明白白。

![DeepSeek Harness 上下文洞察实测：43 个会话跑掉 2.61 亿 Token，工具定义与调用占了 87.5%](https://img.liangxiaoaitool.top/2026/11/dsh-magpie-20261119-03-dsh-context.jpg)

因为我目前日常写代码的主力还是放在 Codex 和 Antigravity 上，这边用得相对少一些，半个月断断续续跑了 43 个会话、总共 **2.61 亿（261.4M）Token**。但光看一眼这张图就明白上一节为什么要提按需路由了：我自己打字发出去的消息只占 `0.1%`（`284.4k`），真正吃掉额度的全是工具定义（`44.8%`）和工具调用（`42.7%`），两项加起来占了整整 `87.5%`。以前在黑框终端里总觉得额度掉得莫名其妙，现在两个看板对着看，钱和额度花哪儿心里一下就有数了。

## 最后

总结下来，`Magpie` 把**傻瓜式反代路由、Skill / MCP / 子代理全局共用、多账号与本地 Agent 消耗看板**这几件事做得足够省心；`DeepSeek Harness` 则提供了一副能随便折腾插件的开源骨架。

把好用的大模型和工具库当内核，放进一个更能自由 DIY 的 Agent 壳子里，能发挥出来的作用比守着某一个死板客户端大得多。如果你手里也有好几个会员账号、平时爱折腾自己的工作流，直接把第一节那句提示词发给本地 AI 让它装上，自己动手改两下就能体会到了。

我是良逍，平时主要记录自己实测过的 AI 工具、独立开发踩坑和产品上线的过程。
