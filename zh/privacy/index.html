隐私权政策

最后更新：2026 年 7 月 13 日

本隐私权政策说明 AdQuiet Chrome 扩展程序如何处理信息。AdQuiet 用于减少 YouTube 桌面端观看页面中的视频广告打断，并尽量减少数据处理。

简要说明：AdQuiet 仅在本地处理相关的 YouTube 页面内容和播放器广告信号，并在 Chrome 扩展程序的本地存储中保存开关设置、汇总计数、时间戳和少量不涉及隐私的诊断事件。AdQuiet 不出售或传输用户个人数据。

1. AdQuiet 处理的信息

为了提供核心功能，AdQuiet 会在浏览器内读取并响应 YouTube 页面中的网站内容和播放器广告信号。这些处理仅在本地进行，只用于识别并减少广告打断。

AdQuiet 使用 chrome.storage.local 在本地保存：

  • 扩展程序是否启用；
  • 与过滤活动有关的汇总计数；
  • 显示近期活动所需的时间戳；
  • 少量固定的、不涉及隐私的诊断事件类型，用于判断扩展程序是否正常工作。

2. AdQuiet 不收集的信息

AdQuiet 不会存储或传输视频标题、完整网页网址、Google 或 YouTube 账户信息、完整播放器响应内容、身份验证信息、付款信息、健康信息、位置数据、个人通讯或浏览记录。

AdQuiet 不会将信息用于信用评估或借贷用途；不会出售用户数据、向数据经纪商传输用户数据、投放个性化广告，也不会允许人工读取用户数据。

3. 权限及用途

storage

用于在设备本地保存启用设置、汇总计数、时间戳和有限的诊断事件。

scripting

用于在需要时在受支持的 YouTube 页面上运行 AdQuiet 的过滤逻辑。

主机访问权限：https://www.youtube.com/*

用于识别播放器广告信号并在 YouTube 桌面端页面上工作。AdQuiet 不请求访问无关网站。

4. 数据共享和网络传输

AdQuiet 不会将本地处理或保存的扩展程序数据发送给开发者或第三方。如果你主动点击外部支持或反馈链接，浏览器只会在你的操作之后打开第三方服务；AdQuiet 不会随该操作自动传输扩展程序数据。

5. 保留和删除

本地扩展程序数据会保留在 Chrome 扩展程序存储中，直到你清除该扩展程序的存储数据或卸载 AdQuiet。按照 Chrome 的通常行为，卸载扩展程序会移除其本地保存的扩展程序数据。

6. Chrome 应用商店“有限使用”声明

AdQuiet 对从 Google API 获得的信息的使用将遵守 Chrome 应用商店用户数据政策，包括“有限使用”要求。

7. 儿童隐私

AdQuiet 并非为了收集儿童或其他任何用户的个人信息而设计。

8. 政策变更

如果 AdQuiet 的信息处理方式发生重大变化，本页面将更新，并修改“最后更新”日期。

9. 联系方式

如有隐私相关问题，请使用 AdQuiet 支持页面，或通过 X 联系开发者。

AdQuiet 是独立扩展程序，与 YouTube 或 Google 不存在关联，也未获得其认可或赞助。
